# 数据处理算法流程

## 1. 总体流程

```text
DCA1000 BIN
→ I/Q 复数恢复
→ 数据重排
→ 逐 Chirp 距离 FFT
→ 短时窗口划分
→ Doppler FFT
→ 接收通道功率非相干累加
→ 二维 RD 功率背景建模
→ 目标/背景功率比增强
→ 候选点提取
→ 距离–时间轨迹拟合
→ 全局动态规划速度解模糊
→ 精度评价
```

## 2. 单通道二维 RD 复数谱

第 `m` 个接收通道、第 `w` 个短时窗口的二维 RD 结果记为：

```text
X_m(r, v, w)
```

其中：

- `m`：接收通道编号；
- `r`：距离 FFT 单元；
- `v`：Doppler FFT 速度单元；
- `w`：短时窗口编号。

## 3. 接收通道功率累加

```text
P_RD(r,v,w) = Σ_m |X_m(r,v,w)|²
```

程序先对每个接收通道的复数 RD 结果取模平方，再沿接收通道维求和。这属于功率非相干累加，不要求通道间相位标定。

## 4. 二维 RD 背景

对所有枪击前背景窗口，在固定距离–速度单元上取中位数：

```text
P_bg(r,v) = median_w P_RD,bg(r,v,w)
```

中位数可降低少量异常窗口和瞬态干扰对背景估计的影响。

## 5. 功率背景增强

```text
E_RD(r,v,w) = 10 log10[(P_target(r,v,w)+ε)/(P_bg(r,v)+ε)]
```

`E_RD > 0 dB` 表示当前窗口功率高于背景；负值仍保留在数据中，只是在使用 `[0, 35] dB` 色轴时显示为最低颜色。

## 6. 候选点和轨迹

每个窗口先沿速度维取最大背景增强值，得到一条距离轮廓，并记录最大值对应的有模糊速度。随后执行距离门、平滑、局部峰检测、门限、最小距离间隔和数量限制。

候选点只表示“可能是目标”，跨窗口轨迹搜索才确定最终连续目标序列。详细说明见 `candidate_extraction.md` 和 `track_fitting.md`。

## 7. 速度解模糊

有模糊速度和真实速度满足：

```text
v(i,k) = v_alias(i) + k · 2Vmax
```

动态规划的总代价同时考虑：

- 与外部实测速度的偏差；
- 与距离–时间拟合速度的偏差；
- 相邻时刻解模糊速度的连续性。

## 8. 评价指标

```text
velocity_error(i) = v_unwrapped(i) - v_measured
MAE = mean(|velocity_error|)
RMSE = sqrt(mean(velocity_error²))
minimum_absolute_error = min(|velocity_error|)
```

最小绝对误差只说明至少有一个速度点接近实测值，整条轨迹的总体精度仍应以 RMSE 和 MAE 为主要依据。
