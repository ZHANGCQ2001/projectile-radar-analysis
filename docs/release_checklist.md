# 发布与交付检查清单

[返回文档索引](README.md) · [发布步骤](github_publish.md)

此清单用于逐次验收；空框不表示已通过。本轮文档整理不替代下列测试和授权检查。

## 版本与入口

- [ ] 确认交付分支、提交号/标签；README描述的功能与该提交一致。
- [ ] 明确交付的是完整源码、改动补丁还是独立安装程序，不混用名称。
- [ ] 在新目录按 `startup; app = RadarControlMachineApp;` 启动，确认没有命中旧副本。
- [ ] 记录MATLAB、操作系统与工具箱版本；未验证的最低版本不做承诺。
- [ ] 完整工程包括JSON模板、算法包、界面包；相对路径及可写目录有效。

## 两个界面

- [ ] 界面1没有旧单目标解模糊/拟合控件，原始ADC/1D FFT/RD仍可查看。
- [ ] 最大SNR图按物理帧汇总，NaN不伪造成0，只显示一条当前帧线。
- [ ] 反复切帧、切视图、长短文件互换、修改窗长后不保留旧标记/缓存。
- [ ] 界面1目标帧范围传入界面2；默认背景须人工确认不含目标。
- [ ] 界面2横向距离、方向、投影阈值、参考速率与范围收集正确。
- [ ] 复查两个界面不同的去均值、RX合并和dB定义，不把一套默认值当另一套。

## 算法与数据

- [ ] 单元测试全部通过，并记录失败/不完整项，不只检查脚本结束。
- [ ] 两个离线GUI回归脚本通过；有桌面环境时另查布局、中文显示和截图。
- [ ] 用已知参数数据核验IQ顺序、帧边界、距离轴、速度符号和时间轴。
- [ ] 区分径向解模糊速度与 `TargetSpeed_mps`；相对参考值RMSE不称独立精度。
- [ ] 核查d=0、接近/远离、R<=d、近最近点和无可行路径情形。
- [ ] 检查MAT/CSV字段及空表行为；不同运行不混用旧导出文件。
- [ ] 样本帧1～10与源帧126～135映射正确，完整案例配置未误用于裁剪数据。
