# 距离–时间轨迹拟合

## 1. 初始直线假设

从不同短时窗口选择两个候选点：

```text
(t1, R1), (t2, R2)
```

生成：

```text
speed = (R2 - R1)/(t2 - t1)
intercept = R1 - speed·t1
R_pred(t) = speed·t + intercept
```

只有满足速度搜索范围和最小时间跨度的假设会进入下一步。

## 2. 每个窗口的候选关联

对当前直线假设，计算每个候选点的：

- 距离残差；
- 与假设速度折叠值的循环速度残差；
- 与实测速度折叠值的循环速度残差；
- 相对背景强度。

每个窗口最多选择一个综合代价最低的候选点。

## 3. 轨迹评分

轨迹评分不是只看“包含多少点”，而是综合：

```text
点数奖励
+ 总增强强度奖励
- 平均距离残差惩罚
- 平均循环速度残差惩罚
```

点数通常是最主要因素；当点数接近时，距离残差、速度一致性和强度决定最终结果。

## 4. 迭代最小二乘

初始轨迹选出后，用全部已选点执行一次直线最小二乘：

```text
min Σ [R_i - (v·t_i + b)]²
```

再使用新直线重新关联所有窗口的候选点。该过程重复，直到候选集合不再变化或达到最大迭代次数。

## 5. 最终结果

最终输出：

- 距离拟合速度；
- 拟合截距；
- 每个点的拟合距离；
- 每个点的距离残差；
- 距离拟合 RMSE；
- 距离拟合速度对应的理论有模糊速度；
- 轨迹有模糊速度与理论值的循环残差。
